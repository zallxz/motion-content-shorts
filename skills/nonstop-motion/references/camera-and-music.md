# 3D world, camera shots & music sync

With `meta.world: "3d"` (the default), a low-poly 3D world renders behind the motion graphics. Every beat is one camera **shot** on one **set**, and every cut is locked to the music's beat grid.

## Sets (locations)
| set | what's there | default for |
|---|---|---|
| `desk` | room corner at night, window onto the city, desk, glowing laptop, lamp, plant, shelf, Blip on the desk | dialog, ui, chat, statements |
| `rooftop` | rooftop with crate, water tank, AC fans, blinking antenna, string lights, full skyline, moon | hook, cta, statements |
| `stage` | abstract podium, glowing arch, orbiting rings, floating shapes, pulsing colored lights | stat, list, compare, punch |

The theme re-lights everything: `midnight` gives a night city, `paper` warm pastel daylight, `terminal` a neon-green hacker night, and `editorial` a clean "clay render" daylight.

Override per beat: `"set": "rooftop"`.

## Shot library
| shot | move | feels like |
|---|---|---|
| `push-in` | slow dolly toward subject | focus, intimacy |
| `pull-out` | dolly back + drift | reveal, ending |
| `orbit` | arc around subject | showing, explaining |
| `crane-up` | rise and tilt down | uplift, conclusion |
| `crane-down` | drop from above | arrival, opening |
| `dutch-push` | tilted horizon + push | tension, unease |
| `snap-zoom` | very fast zoom then drift | hook, shock |
| `whip` | fast swing into frame | energy, punchline |
| `truck` | lateral slide | lists, comparisons |
| `low-hero` | low angle looking up | confidence, "smug" |
| `top-down` | overhead + rotate | data, overview |
| `vertigo` | dolly-zoom (subject stays, world stretches) | realization, big numbers |
| `spiral` | orbit + push + descend | build-up |
| `screen` | push into the laptop screen | ui and chat beats |

With `"shot": "auto"` (default), each beat type picks from a fitting list, never repeats the previous shot, and alternates direction (left/right) beat to beat. Override per beat: `"shot": "vertigo"`.

**Composition for vertical video:** distances are scaled for 9:16, and the camera tilts up so the subject sits in the lower half while the graphics own the top half.

## Music sync
- Default tracks are **generated by `scripts/make-music.mjs`**: original, royalty-free, safe for commercial use.
  - `chill` → 92 bpm half-time lo-fi
  - `fast` → 118 bpm four-on-the-floor synth-pop
  - `hyper` → 140 bpm with trap hat rolls
- Every beat's length is rounded **up** to a whole number of musical beats, so cuts land exactly on kicks and readability is never cut short.
- On every kick:
  - the camera FOV punches in
  - Blip squashes
  - the antenna bulb and stage lights flash
  - the 2D layer pulses slightly
  - bar downbeats hit harder
- **SFX:** a whoosh starts just before each cut, and an impact lands on the hook and on punches. Turn them off with `"sfx": false`.

### Using your own music
```json
"music": { "file": "music/mytrack.mp3", "bpm": 124, "volume": 0.5 }
```
- Put the file in `template/public/music/`.
- **Trim the track so its first downbeat is at 0:00.** Otherwise cuts drift off the beat.
- Use the track's real BPM (tap-tempo or check the source).
- Use only music you have rights to.

New generated track: `npm run music -- --bpm 128 --bars 32 --style fast --out public/music/my-128.wav`

Silent video: `"music": false`.

## Render speed
3D rendering uses software WebGL (`swangle`) so it works on any machine. Expect roughly 1–2 s per frame on a 2-core server, which is about 8–15 min for a 25 s video. On a laptop with a GPU, set `Config.setChromiumOpenGlRenderer("angle")` in `remotion.config.ts` for big speedups. For drafts, render at `--scale=0.4`, or use `"world": "flat"` (2D only, about 3× faster).
