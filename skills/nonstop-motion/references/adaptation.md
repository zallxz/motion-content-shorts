# Adapting to any context

The skill is not tied to one niche. Find the niche below, or the closest one, and take its theme, tempo and arc. Then write the beats in the creator's own language.

## Niche → defaults

| niche | theme | tempo | mascot | default arc |
|---|---|---|---|---|
| AI / tech / SaaS | midnight | fast | yes | Story/POV or Problem→Twist |
| dev humor / programming | terminal | hyper | yes | Story/POV |
| science / psych facts | paper | fast | yes | Number-first |
| education / how-to | paper | fast | optional | Listicle |
| finance / money | editorial | fast | no | Myth→Truth |
| business / productivity | editorial | fast | no | Versus |
| news / explainer | editorial | chill | no | Build-up→Punch |
| motivation / story | midnight | chill | optional | Build-up→Punch |
| comedy / meme / relatable | paper or terminal | hyper | yes | Story/POV |
| product launch | midnight or paper | fast | brand mascot / none | Problem→Twist |
| food / lifestyle | paper | fast | optional | Listicle |

If a niche is missing, ask: *Is it serious, playful or nerdy?* Serious → editorial. Playful → paper. Nerdy or tech → terminal or midnight.

## Arcs (beat sequences)

**Problem → Twist** (product, tips)
`hook(pain) → statement(why it happens) → ui/stat(proof) → punch(twist) → list(fix) → cta`

**Myth → Truth** (finance, health, education)
`hook("X itu salah") → statement(the myth) → compare(myth vs truth, winner) → stat(evidence) → punch(rule) → cta(save)`

**Story / POV skit** (relatable, humor)
`hook(POV kicker) → dialog → ui/chat(the evidence) → dialog(reaction) → dialog(comeback) → punch(the joke lands) → list(lesson, optional) → cta(comment)`

**Listicle** (tips, tools)
`hook("3 X yang...") → statement(context) → list(items) → punch(best one / bonus) → cta(save)`
For 5+ items, split into two `list` beats with a `stat` or `punch` between them.

**Versus** (choices)
`hook("A atau B?") → compare → statement(when A wins) → statement(when B wins) → punch(verdict) → cta(comment your pick)`

**Number-first** (facts)
`hook(surprising claim) → stat(the number) → statement(what it means) → compare/list(implication) → punch → cta`

**Build-up → Punch** (story, motivation, news)
`hook → statement ×2–3 (rising stakes, change transition each time) → stat/ui(the turn) → punch(the line) → cta`

## Length guide
- 15–20 s → 5–6 beats (memes, single facts)
- 20–30 s → 7–9 beats (default)
- 30–45 s → 10–13 beats (stories, listicles). Add a mid-video `punch` to reset attention.

## Language & voice
- Write the way the creator speaks: Indonesian casual (lu/gw, "anjir", "gak"), formal Bahasa, English, or a mix. The fonts render the full Latin set (Indonesian, Spanish, etc.). CJK or Arabic needs an added font (see `extending.md`).
- Short words read faster. Prefer "gak" over "tidak" for casual audiences.
- Put the emphasis `*word*` on the word that carries the meaning, not on filler.

## Example: same topic, three contexts
Topic: "Most people check their phone 100+ times a day" (only if sourced; otherwise label it an example).
- **Paper / education:** hook "Lu buka HP lebih sering dari kedip?" → stat → statement → list(3 tricks) → cta(save)
- **Midnight / story:** hook(kicker "POV") "HP lu ngomong balik" → dialog(phone mascot: "Kangen ya?") → chat(notifications) → punch → cta
- **Editorial / productivity:** hook "Fokus lu dijual" → statement → compare(attention vs. ads revenue) → punch "Matikan notifikasi." → cta
